🛡️ НЕСЪЕМНЫЙ БИЛД И ПРОКАЧКА УРОВНЕЙ

В этом забеге вы собираете постоянный билд из максимум 18 слотов:

  • Несъемный выбор: Если вы нажимаете [ + ACCEPT & LOCK IN ], способность навсегда закрепляется в активном билде текущего забега.
  • Прокачка только экипированных: Уровень (LV 1 → LV 10) и прогресс растут исключительно у экипированных навыков по мере продолжения боя в этом стиле. Неэкипированные предложения остаются на LV 1.
  • Лимит 18 слотов: Заполнив 18 слотов, вы фиксируете финальную колоду оператора.
  • Двойная фильтрация: В панели под игрой можно фильтровать способности одновременно по баффу, дебаффу и текстовому поиску.

🏆 КЛАССЫ СТИЛЯ (STYLE CLASSES: D → SSS)

Каждому навыку присвоен класс стиля, отражающий его редкость, глубину комбо и силу:

Class D: Базовые одиночные маневры (Move) Class C: Тактическое позиционирование (Sniper, Point-Blank, Dash) Class B: 2-шаговые тактические комбо (Move→Dash, Charge) Class A: Редкие хай-скилл действия и парирование (Parry, Boss, Crit→Kill) Class S: Рипосты, снайперские рывки и выстрелы с выката Class SS: 3-шаговые мастер-комбо (Dash→PointBlank→Kill) Class SSS: 4-шаговые ультимативные цепочки казни
